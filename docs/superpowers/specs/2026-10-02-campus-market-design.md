# 校园二手交易平台设计文档

日期：2026-10-02
课程：数据库原理作业
目标：开发一个包含数据库的可运行软件系统（Python + SQLite 的校园二手交易平台）

## 1. 项目概述

校园二手交易平台，面向校内学生。卖家发布闲置商品并定价，买家按商品名搜索、按价格区间和分类筛选，看中后在系统内下单，双方确认后完成交易。不限品类，覆盖教材、数码、宿舍用品等校园常见闲置物。

作业硬性要求：（1）可以运行；（2）包含数据库，数据自行设计创建。

## 2. 技术栈

- Python 3.12
- Flask（网页应用，服务端渲染 HTML）
- SQLite（Python 标准库 `sqlite3`），原生 SQL，不使用 ORM
- 密码存储：`werkzeug.security` 哈希，不存明文
- 依赖只有 Flask 一个

项目结构（代码放在 `campus_market/`）：

```
campus_market/
├── app.py            # Flask 路由 + 业务逻辑
├── database.py       # 连接数据库、建表、写入示例数据
├── schema.sql        # 建表 SQL
├── templates/        # HTML 页面
├── static/style.css  # 样式
└── tests/test_app.py # 核心功能测试
```

数据库文件为 `campus_market/campus_market.db`。首次运行时自动建库建表并写入示例数据；若文件已存在则不重复初始化。

## 3. 数据库设计

四张表。建表时声明主键、外键、非空、CHECK 约束，保证引用完整性。

### categories（分类）

| 字段 | 类型 | 约束 |
|---|---|---|
| id | INTEGER | 主键 |
| name | TEXT | 唯一、非空 |

七个固定分类：教材书籍、手机数码、数码配件、宿舍生活、交通出行、服饰运动、其他闲置。

### users（用户）

| 字段 | 类型 | 约束 |
|---|---|---|
| id | INTEGER | 主键 |
| username | TEXT | 唯一、非空 |
| password | TEXT | 非空（哈希值） |
| role | TEXT | 非空，取值 buyer / seller，默认 buyer |
| contact | TEXT | 联系方式（微信 / 手机号） |
| created_at | TEXT | 非空 |

### items（商品）

| 字段 | 类型 | 约束 |
|---|---|---|
| id | INTEGER | 主键 |
| title | TEXT | 非空（商品名，搜索字段） |
| price | REAL | 非空，CHECK price > 0（价格，筛选字段） |
| condition | TEXT | 成色：全新 / 九成新 / 八成新 / 有使用痕迹 |
| description | TEXT | 商品描述 |
| status | TEXT | 非空，取值 在售 / 已售 / 下架 |
| category_id | INTEGER | 外键 → categories.id，非空 |
| seller_id | INTEGER | 外键 → users.id，非空 |
| created_at | TEXT | 非空 |

### orders（订单）

| 字段 | 类型 | 约束 |
|---|---|---|
| id | INTEGER | 主键 |
| item_id | INTEGER | 外键 → items.id，非空 |
| buyer_id | INTEGER | 外键 → users.id，非空 |
| price | REAL | 非空（下单时成交价快照） |
| status | TEXT | 非空，取值 待交易 / 已完成 / 已取消 |
| created_at | TEXT | 非空 |

### 示例数据

首次运行写入：7 条分类、约 10 个用户（买家 / 卖家混合）、约 30 件商品（覆盖各分类、不同价格带）、若干订单（三种状态都有）。便于演示搜索、筛选和订单流转。

## 4. 页面与功能

1. **首页 / 商品市场**：分类标签栏（7 类可点，可不选）+ 商品名搜索框 + 价格区间（最低价 / 最高价）+ 商品卡片列表（商品名、价格、成色、分类、卖家）。三个筛选条件可任意组合，也可只用其一。搜索框留空表示不按名称过滤；价格留空表示不限该端（只填最低价即为「≥ 最低价」）。
2. **商品详情页**：完整信息 + 卖家联系方式 + 「购买」按钮（当前身份为买家且商品在售时显示）。
3. **注册页**：用户名、密码、联系方式，注册后默认买家身份。
4. **登录页**：用户名 + 密码，登录后写 session。
5. **发布商品页**（卖家）：商品名、分类下拉、价格、成色、描述。
6. **我的商品页**（卖家）：自己发布的商品列表，可改价、可下架。
7. **我的订单页**（买家）：自己下的单。「待交易」可取消，可确认完成。
8. **卖出记录页**（卖家）：别人买自己商品的订单，可确认完成。
9. **设置页**：一键切换买家 / 卖家身份（改 `users.role`，立即生效）；修改联系方式。

导航栏随当前身份变化：买家显示「商品市场 / 我的订单 / 设置」，卖家显示「商品市场 / 发布商品 / 我的商品 / 卖出记录 / 设置」。

## 5. 业务规则

- 当前身份为买家才能下单；当前身份为卖家才能发布、管理商品。身份可在设置页随时切换。
- 不能购买自己发布的商品（按 `seller_id` 与当前用户 id 比较，与身份无关）。
- 商品状态为「已售」或「下架」时不能下单。
- 下单成功后商品置为「已售」；订单「已取消」时商品恢复「在售」。
- 订单状态流转：待交易 → 已完成（买家或卖家确认）；待交易 → 已取消（仅买家可取消）。
- 只有商品发布者本人能改价、下架自己的商品。
- 商品状态为「已售」时不可改价、不可下架，等订单走完后再处理。
- 下架的商品不出现在市场列表，但仍可在「我的商品」中看到。

## 6. 错误处理

- 登录态用 Flask session。未登录访问发布、订单、设置等页面时跳转登录页。
- 所有 SQL 使用参数化查询，防注入。
- 表单校验：用户名密码非空、价格为正数、价格区间输入为合法数字、下单数量条件不满足时返回页面并提示原因，页面不崩。
- 重复用户名注册时提示已存在。

## 7. 测试

`tests/test_app.py` 覆盖核心链路：

- 注册、登录、身份切换
- 发布商品、改价、下架
- 搜索（商品名模糊）、价格区间筛选、分类筛选及组合查询
- 下单成功后商品变为已售
- 不能买自己的商品、不能买已售 / 下架商品
- 订单取消后商品恢复在售
- 订单状态流转到已完成

用 Flask test client + 内存或临时 SQLite 库跑，不依赖浏览器。
